# Breakdown

Copy page

_Available since v2.5.0_

Umami Breakdown allows you to aggregate and view your data in a variety of ways. Explore your data more extensively through the utilization of segments and filters.

The insight works by segmenting your data into the following metrics.

- **Visitors**
- **Visits**
- **Views**
- **Bounce Rate**
- **Visit Duration**

## Parameters[#](https://docs.umami.is/docs/breakdown#parameters)

| Parameter | Description |
| --- | --- |
| Fields | (required) Metric data you want to segment. This is defaulted to Path and includes all data collected via the tracker script. |
