# Notifications

Copy page

Umami allows you to turn off email notifications about product features and updates.

## Email preferences[#](https://docs.umami.is/docs/cloud/notifications#email-preferences)

Log into Umami and click on the side nav profile button then click **Settings**.

![image](https://docs.umami.is/images/cloud/navbar-settings.png)

Navigate to **Notifications** and toggle on/off the email preferences for the account.

![image](https://docs.umami.is/images/cloud/notification-form.png)
