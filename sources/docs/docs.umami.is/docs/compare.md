# Compare

Copy page

_Available since v2.12.0_

Umami supports comparing websites stats and metrics across previous date ranges. See how your website performs versus the past and if it's trending in the right direction.

## Parameters[#](https://docs.umami.is/docs/compare#parameters)

| Parameter | Description |
| --- | --- |
| Previous date range | (required) Comparison date range which can be the previous period or year. |

## Create an insight[#](https://docs.umami.is/docs/compare#create-an-insight)

### Step 1: Choose a previous date range[#](https://docs.umami.is/docs/compare#step-1-choose-a-previous-date-range)

- **Previous period**: Same date range from the most recent past period.
- **Previous year**: Same date range last year.

![image](https://docs.umami.is/images/docs/compare-date.png)

### Step 2: Run insight[#](https://docs.umami.is/docs/compare#step-2-run-insight)

Compare mode will show website stats along with performance changes between the two periods. The graph will also display **Views** (Purple) and **Visitors** (Pink) lines from the previous period.

![image](https://docs.umami.is/images/docs/compare-graph.png)

Compare individual metric stats. Each metric displays a percentage change indicator showing how it has changed compared to the previous period. A green indicator means improvement, while red indicates a decline.

![image](https://docs.umami.is/images/docs/compare-metrics.png)
