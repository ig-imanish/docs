# Login

Copy page

Your Umami installation will create a default administrator account with the username **admin** and the password **umami**.

The first thing you will want to do is log in and change your password.

![image](https://docs.umami.is/images/docs/login.png)

Once logged in, click on the side nav profile button then click **Settings**.

![image](https://docs.umami.is/images/docs/navbar-settings.png)

Then navigate to **Profile** and click the **Change password** button.

![image](https://docs.umami.is/images/docs/change-password.png)

You can also enable [two-factor authentication](https://docs.umami.is/docs/two-factor-authentication) from the **Security** tab for extra account protection.
