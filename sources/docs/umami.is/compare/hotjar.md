## One tool instead of two

Hotjar shows you how users behave, but it has no traditional web analytics — no pageview trends, referrers, or campaign reporting — so most teams run it alongside Google Analytics. Umami combines both: session replay and heatmaps for behavior, plus complete web analytics with funnels, cohorts, and revenue tracking, in one privacy-first dashboard.

## No session caps, no tier ladders

Hotjar meters everything by daily session caps — 35 on the free plan — and locks funnels, journeys, and API access behind higher tiers, with observation and feedback sold as separate subscriptions. Umami has no daily session caps, funnels and journeys are on every plan, self-hosting is free and unlimited, and Umami Cloud pricing scales simply with events.

## Privacy by default, not by configuration

Hotjar sets cookies that persist for a year, which means consent banners and careful GDPR configuration — recordings only start after visitors opt in. Umami is cookie-free and collects no personal data, so it is compliant by default and captures every visit without asking permission to watch.

## Frequently asked questions

Is Umami a good alternative to Hotjar?

Yes. Umami includes session replay and heatmaps — the core of Hotjar — plus the full web analytics Hotjar lacks: pageviews, referrers, UTM campaigns, funnels, cohorts, and revenue tracking. One tool instead of Hotjar plus a separate analytics product.

Does Hotjar require a cookie consent banner?

Yes. Hotjar uses cookies (including a visitor cookie that persists for 365 days), so under GDPR it must be blocked until visitors consent. Umami is cookie-free and collects no personal data, so no consent banner is needed.

How does Umami pricing compare to Hotjar?

Hotjar prices by daily session caps and splits features across separate Observe and Ask subscriptions, with funnels and API access on top tiers. Umami Cloud is free to start with plans from $20/month and no daily session caps, and self-hosting is completely free.

Does Umami have surveys like Hotjar?

No. Hotjar’s feedback widgets and surveys are its remaining differentiator. If you need on-page surveys, you can pair Umami with a dedicated survey tool — while still consolidating replays, heatmaps, and analytics in Umami.
