## Install in minutes

Deploy Umami with a single Docker command or connect to Umami Cloud. Add one script tag to your site and you are collecting data immediately. No complex data streams, tag managers, or SDK integration required.

![Install in minutes](https://umami.is/images/screenshot-dashboard.jpg)

## Track custom events with a data attribute

Add data-umami-event to any HTML element to start tracking clicks, form submissions, signups, or downloads. Attach custom properties with data-umami-event-\* attributes. No SDK calls, no event schemas to configure — just markup.

![Track custom events with a data attribute](https://umami.is/images/feature-events.png)

## Build with the REST API

Every piece of data in Umami is accessible through a well-documented REST API. Pull stats into internal dashboards, feed data into CI pipelines, generate custom reports, or build integrations with your existing tools.

![Build with the REST API](https://umami.is/images/feature-stats.png)

## Monitor performance and Core Web Vitals

Track page load times and web performance metrics alongside your traffic data. See how speed affects bounce rate and engagement without needing a separate monitoring tool.

Watch real user sessions to understand how visitors interact with your site. See exactly what happened when a user reported a bug — what they clicked, where they scrolled, and where things went wrong.
