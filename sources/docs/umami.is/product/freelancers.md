## One dashboard for every project

Add all your websites, side projects, and client sites to a single Umami instance. Switch between them instantly and see real-time traffic for each one without juggling multiple analytics accounts.

## Set up in under five minutes

Add one script tag to your site and start collecting data. No tag managers, no data streams, no configuration wizards. Whether it's a portfolio site, a SaaS landing page, or a client project, you're live in minutes.

![Set up in under five minutes](https://umami.is/images/screenshot-dashboard.jpg)

## Track what matters with custom events

Monitor contact form submissions, download clicks, pricing page visits, and any other action that drives your business. Just add a data attribute — no JavaScript SDK or complex setup required.
