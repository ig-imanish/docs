# Overview

Copy page

Umami allows you to pull data directly by calling the application's API endpoints. Any operation you can do through the application is available in the API. All data is returned in JSON format.

### Self-hosting[#](https://docs.umami.is/docs/api#self-hosting)

When self-hosting, the API endpoints are available at `http://<your-umami-instance>/api`. You would first need to [authenticate](https://docs.umami.is/docs/api/authentication) before making calls.

### Umami Cloud[#](https://docs.umami.is/docs/api#umami-cloud)

If using Umami Cloud, you would make calls to `https://api.umami.is` using an [API key](https://docs.umami.is/docs/cloud/api-key).
