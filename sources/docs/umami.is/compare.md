# How Umami compares

One privacy-first platform for traffic, campaigns, behavior, conversions, and revenue. See how Umami stacks up against your current analytics tool.

## Privacy by default

Umami collects no personal data, uses no cookies, and is GDPR and CCPA compliant out of the box. No consent banners needed.

## Open source (MIT)

Fully open source under the permissive MIT license. Self-host for free, inspect the code, or contribute.

## Simple & fast

A clean, real-time dashboard that shows you what matters. Set up in minutes with a single script tag.

## Full-featured

Custom events, funnels, user journeys, session replay, revenue tracking, UTM campaigns, and more.
