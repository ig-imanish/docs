---
title: "List All Websites You Have Access To"
sidebarTitle: "List Websites"
description: "Retrieve a paginated list of websites you own or can access through team membership, with optional search, sorting, and result-limit controls."
---

Use this endpoint to fetch every website your API key can access. The response is paginated, so you can iterate over large sets with the `page` and `pageSize` parameters. Pass `includeTeams` to also return websites made available to you through team membership.

`GET /api/websites`

## Request

### Headers

<ParamField header="Authorization" type="string" required>
  Bearer token. Pass your API key: `Authorization: Bearer <api-key>`
</ParamField>

### Query Parameters

<ParamField query="page" type="integer">
  Page number to return, starting at `1`. Defaults to `1`.
</ParamField>

<ParamField query="pageSize" type="integer">
  Number of website records to return per page. Defaults to server-defined limit.
</ParamField>

<ParamField query="maxResults" type="integer">
  Hard cap on the total number of results included across all pages.
</ParamField>

<ParamField query="search" type="string">
  Filter websites by name or domain. The search is case-insensitive and matches partial strings.
</ParamField>

<ParamField query="orderBy" type="string">
  Field name to sort results by, e.g. `name`, `domain`, or `createdAt`.
</ParamField>

<ParamField query="sortDescending" type="string">
  Set to `true` to reverse the sort order. Accepted values: `true`, `false`.
</ParamField>

<ParamField query="includeTeams" type="string">
  When present with any non-empty value, websites accessible through teams you own or manage are included in the results.
</ParamField>

## Response

**200 – Success**

<ResponseField name="count" type="integer" required>
  Total number of website records matching the query.
</ResponseField>

<ResponseField name="data" type="Website[]" required>
  Array of website objects. Each object contains the fields below.
</ResponseField>

<ResponseField name="data[].id" type="string">
  Unique UUID of the website.
</ResponseField>

<ResponseField name="data[].name" type="string">
  Human-readable display name of the website.
</ResponseField>

<ResponseField name="data[].domain" type="string">
  Domain tracked by this website, e.g. `example.com`.
</ResponseField>

<ResponseField name="data[].shareId" type="string | null">
  Token used to access the website's public share page. `null` if sharing is disabled.
</ResponseField>

<ResponseField name="data[].teamId" type="string | null">
  UUID of the team this website belongs to. `null` for personal websites.
</ResponseField>

<ResponseField name="data[].userId" type="string | null">
  UUID of the user who owns the website.
</ResponseField>

<ResponseField name="data[].recorderEnabled" type="boolean">
  Whether session recording is enabled for this website.
</ResponseField>

<ResponseField name="data[].resetAt" type="string | null">
  ISO 8601 timestamp of the last analytics data reset, or `null` if never reset.
</ResponseField>

<ResponseField name="data[].createdAt" type="string | null">
  ISO 8601 timestamp when the website was created.
</ResponseField>

<ResponseField name="data[].updatedAt" type="string | null">
  ISO 8601 timestamp when the website was last updated.
</ResponseField>

<ResponseField name="page" type="integer" required>
  The current page number returned.
</ResponseField>

<ResponseField name="pageSize" type="integer" required>
  Number of results per page for this response.
</ResponseField>

<ResponseField name="orderBy" type="string">
  Field used to sort the results.
</ResponseField>

<ResponseField name="search" type="string">
  The search string applied to this result set, if any.
</ResponseField>

## Code Sample

