# Product brief

## Description

Datasite measures website traffic and product usage. It brings analytics, events, sessions, conversions, revenue, recordings, performance, errors, sharing, and API access into one product.

## Primary audience

The primary readers are website owners, product teams, marketers, and developers who configure tracking and use Datasite reports. This audience is inferred from the supplied feature and setup guides.

## Jobs to be done

- Add a website, install its tracking script, and verify collection.
- Understand traffic, sessions, events, conversions, revenue, and product-quality reports.
- Configure privacy, workspace access, billing, sharing, data transfer, and API access safely.

## Motivation

Datasite gives teams one place to collect and analyze website and product data. The supplied source emphasizes flexible tracking, privacy controls, operational reports, and workspace-scoped access.
