Datasite conversion reports measure completed actions, ordered paths, common journeys, and return behavior. Create goals and funnels only after their page or event data starts arriving.

## Goals

<Steps>
  <Step title="Open Goals">
    Open a website and go to **Reports → Goals**.
  </Step>
  <Step title="Define the conversion">
    Create a goal and select its page or event condition.
  </Step>
  <Step title="Review results">
    Save the goal, then open it to view results for a date range.
  </Step>
</Steps>

Renaming an event in application code does not rewrite older analytics.

## Funnels

<Steps>
  <Step title="Open Funnels">
    Open **Reports → Funnels**.
  </Step>
  <Step title="Add ordered steps">
    Add each page or event in conversion order, then save the funnel.
  </Step>
  <Step title="Review drop-off">
    Review completion and drop-off at each step.
  </Step>
</Steps>

Funnel results depend on event order and the selected date and filter context. Aggregate-only imported data may not contain enough detail to reconstruct a funnel.

## Journeys

Journeys show common entry and exit paths. Use filters to focus on a campaign, page, audience, or another supported segment.

## Retention and cohorts

Retention groups users or sessions by their initial period and measures return activity in later periods. Cohort views can also compare revenue behavior where revenue data exists. Recent cohorts have fewer completed periods, so account for maturity when comparing them.
