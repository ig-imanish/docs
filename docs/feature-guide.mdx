Datasite combines website analytics, product behavior, conversion reporting, operational monitoring, and data access. Use this guide to find the feature that matches your task.

| Feature | Purpose |
| --- | --- |
| Overview | Page views, visitors, visits, bounce rate, visit duration, trends, and comparisons |
| Pages | Popular URLs, page titles, entry pages, and exit pages |
| Acquisition | Referrers, channels, UTM campaigns, advertising click IDs, and attribution |
| Audience | Countries, regions, cities, languages, browsers, operating systems, devices, and screens |
| Events | Named product actions and their custom properties |
| Sessions | Visit timelines, page activity, events, and identified user properties |
| Realtime | Current active visitors and recent activity, including a geographic globe |
| Session replay | Playback of recorded browser sessions |
| Heatmaps | Aggregated click and scroll behavior for a page |
| Errors | Grouped browser exceptions with stack, environment, release, and device details |
| Performance | LCP, INP, CLS, FCP, and TTFB reports |
| Goals | Conversion rules based on pages or events |
| Funnels | Ordered conversion steps with completion and drop-off counts |
| Journeys | Common entry and exit paths |
| Retention and cohorts | Return behavior for groups of visitors or sessions |
| Revenue | Revenue totals, trends, events, sessions, and cohort views |
| Experiments | Weighted variants, exposure tracking, conversion results, and winner status |
| AI agents | Traffic identified as coming from AI agents or AI referral sources |
| Segments | Reusable saved filter sets |
| Annotations | Dated notes displayed with analytics charts |
| Boards | Custom collections of analytics components |
| Sharing | Public links for selected websites, boards, links, or pixels |
| Tracked links | Short redirect URLs with click analytics |
| Tracking pixels | Pixel URLs for measuring opens or requests |
| Import and export | Bring supported analytics data into Datasite or download Datasite data |
| API and MCP | Read analytics through API keys, the TypeScript client, or read-only MCP tools |
