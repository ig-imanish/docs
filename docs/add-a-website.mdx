Add a separate Datasite website for each reporting property. The website's setup page provides the tracking snippet and unique website ID.

<Steps>
  <Step title="Open Websites">
    Sign in to Datasite and open **Websites**.
  </Step>
  <Step title="Start adding a website">
    Select **Add website**.
  </Step>
  <Step title="Enter website details">
    Enter a name and domain, then save the website.
  </Step>
  <Step title="Get the tracking snippet">
    Open the website's **Settings → Setup** page and copy the generated snippet.
  </Step>
</Steps>

Do not reuse one website ID across unrelated domains. Follow the [tracking installation guide](/docs/install-tracking-script) to add the snippet to your site.
