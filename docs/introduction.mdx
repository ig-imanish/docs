Datasite measures website traffic and product usage from one dashboard. It combines audience and acquisition reports with events, sessions, conversions, revenue, replay, heatmaps, errors, performance, and data access.

## How Datasite works

Add a website, then install its unique tracking script in the shared `<head>` or root layout. The tracker records enabled page, session, event, acquisition, audience, performance, and quality data for that website.

Use a separate website ID for each unrelated reporting property. You can control persistent visitor identity, Do Not Track behavior, URL detail collection, performance data, and recording through tracker options and website settings.
